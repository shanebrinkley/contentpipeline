# contentpipeline

**Record once, publish everywhere.** The system I use to turn a single
recording into a week's worth of content — posts, clips, threads —
across every platform. Free and open. Take it, fork it, make it yours.

## the idea

I don't want to write ten different posts for ten different platforms.
So I talk once, and the pipeline does the heavy lifting:

**record → transcribe → pull the story → draft per-platform posts →
grab clip moments → schedule + distribute**

One input. A whole week of output.

## why it's free

I'm building One Thing at a Time in public. This is part of that — the
stuff that helps me should help you too. No signup, no upsell, no catch.
If it saves you time, we're good.
